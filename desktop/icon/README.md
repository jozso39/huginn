# Huginn's icon

- `huginn-original.png` — the drawing it started from (468 px).
- `huginn-art.png` — the final artwork, full-bleed, 1024 px: the eye a yellow dot, a
  slimmer chest, a yellow halo (same yellow, #FFCB2E) centred behind the head, the
  canvas widened so halo and head sit in the middle (the shoulder and chest carried on
  along their slopes). Used for the web icons.
- `huginn-macos.png` — the same on Apple's icon grid (824 px rounded square on a 1024
  canvas, soft shadow). `bunx tauri icon desktop/icon/huginn-macos.png -o
  desktop/src-tauri/icons` makes the app's icon set from it (then drop the Android, iOS
  and Windows files).

A larger original (≥ 1024 px or SVG) would make the large sizes crisper.
